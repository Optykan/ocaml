This is a custom build of ocaml forked from esy to track the upstream changes in ocaml 4.07.
There is a patch available in upstream 4.07 at https://github.com/ocaml/ocaml/commit/00b8c4d503732343d5d01761ad09650fe50ff3a0
This is to patch the alternate signal stack, which you will run into build failures if you don't patch it.

You can pull this patch down with
```
curl -o patch https://github.com/ocaml/ocaml/commit/00b8c4d503732343d5d01761ad09650fe50ff3a0.patch
patch -p1 < patch
```

You also need the patch at 4135828a4b66eb7403d68839da701257c0ccd31e
Do the same...
```
curl -o patch https://github.com/ocaml/ocaml/commit/4135828a4b66eb7403d68839da701257c0ccd31e.patch
patch -p1 < patch
```

Commit the changes, `make` to rebuild (optional, esy will do this for you as well).
